4.0.0-M2

Apache Causeway v4 is based on Spring Boot v4.

This milestone release mitigates a security vulnerability, provides bug fixes and some new features.

Notable changes in this release:

  • address CVE-2025-64408 (CAUSEWAY-3988)

    By default on application start a random HMAC secret (32 bytes) is generated, to digitally sign Viewmodel Bookmarks (URLs). The HMAC secret can also be set via environment variable causeway_hmac_sha256 as comma separated list of signed integers (bytes). A minimum of 16 bytes is required, we recommend 32. (eg. -13,4,0, …​)

  • Open Telemetry integration (CAUSEWAY-3975)

    This activates when dependencies are found on the class path and Spring Profile observation is active.

    For more details, see Open Telemetry Setup

  • Better handling of Eclipse Static weaving (CAUSEWAY-3942, CAUSEWAY-3967, CAUSEWAY-3959, CAUSEWAY-3969)

New Feature

  • CAUSEWAY-3989 - [CommandLog] Bulk-Export and -Upload of Commands

  • CAUSEWAY-3982 - extend auditing to only log on updates, not create or delete.

  • CAUSEWAY-3975 - Open Telemetry Integration
